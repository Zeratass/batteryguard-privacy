# Akku Wächter – Batterie-Alarm: Datenschutzerklärung

Dieses Repository hostet die öffentliche Datenschutzerklärung der Android-App **Akku Wächter – Batterie-Alarm** von Zeratas.

**Live:** https://zeratass.github.io/batteryguard-privacy/

## Kurzfassung

- Die App erhebt, speichert und überträgt **keine personenbezogenen Daten**.
- Keine Internetberechtigung, kein Tracking, keine Werbung.
- Alle Einstellungen bleiben lokal auf dem Gerät.
- Freiwillige Spenden werden vollständig über Google Play Billing abgewickelt.
